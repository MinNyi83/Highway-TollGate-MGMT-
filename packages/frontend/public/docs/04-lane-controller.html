Input Wiring (Active HIGH)

Loop detectors and serial RX use input pins. Each input has a 10kΩ pull-down resistor to GND to ensure stable LOW when no signal.

# Physical wiring
GPIO 17 ──┬── Loop Detector A (entry)
          └── 10kΩ pull-down to GND

GPIO 18 ──┬── Loop Detector B (exit)
          └── 10kΩ pull-down to GND

GPIO 15 ──── USB-Serial RXD (ticket)
            via CP2102 module

Output Wiring (MOSFET/Relay)

Output pins drive MOSFETs or relay modules. Never sink more than 16mA per GPIO pin (max total 50mA across all GPIO).

# Physical wiring
GPIO 27 ──┬── 1kΩ ── Gate of IRF520 MOSFET
          └── MOSFET drives Red 12V LED

GPIO 22 ──┬── 1kΩ ── Gate of IRF520 MOSFET
          └── MOSFET drives Yellow 12V LED

GPIO 23 ──┬── 1kΩ ── Gate of IRF520 MOSFET
          └── MOSFET drives Green 12V LED

GPIO 24 ──┬── Optocoupler (PC817)
          └── Drives 24V barrier relay

LED Traffic Light — Control Sequence

Three-state LED traffic light system (Red/Yellow/Green) mounted on the gantry controls vehicle flow through each lane. Driven via GPIO through MOSFET relay boards.

Control Sequence Flow

1

🔴 RED — Lane Closed (Default State)

Barrier is closed. No vehicles may proceed. System waits for Loop A to detect approaching vehicle. GPIO 27 = HIGH.

2

🟡 YELLOW — Processing (3-5 seconds)

RFID tag read in progress. Toll validation and deduction happening. Ticket dispensing if needed. GPIO 22 = HIGH.

3

🟢 GREEN — Vehicle May Proceed

Toll paid successfully. Barrier opens. Vehicle passes through. GPIO 23 = HIGH.

4

🔴 RED — Lane Re-Closed

Loop B confirms vehicle cleared. Barrier closes. Return to idle state. All GPIO outputs LOW except GPIO 27 (RED).

Testing — GPIO Verification Script

Run this Python test script to verify all GPIO connections before deploying the lane controller to production. Tests each peripheral independently.

#!/usr/bin/env python3
"""
TollGate Lane Controller — GPIO Test Script
Verifies all peripheral connections before production deployment.
Run: python3 test_gpio.py [--live]
"""

import sys
import time

try:
    import RPi.GPIO as GPIO
except ImportError:
    print("ERROR: RPi.GPIO not installed. Run: pip3 install RPi.GPIO")
    sys.exit(1)

# GPIO Pin Assignments (BCM numbering)
PINS = {
    "loop_detector_a":  17,   # Entry loop (INPUT)
    "loop_detector_b":  18,   # Exit loop (INPUT)
    "led_red":          27,   # Traffic light red (OUTPUT)
    "led_yellow":       22,   # Traffic light yellow (OUTPUT)
    "led_green":        23,   # Traffic light green (OUTPUT)
    "barrier_relay":    24,   # Barrier gate relay (OUTPUT)
    "intercom_ptt":     25,   # Intercom push-to-talk (OUTPUT)
    "ticket_enable":     4,   # Ticket dispenser enable (OUTPUT)
}

INPUT_PINS = ["loop_detector_a", "loop_detector_b"]
OUTPUT_PINS = ["led_red", "led_yellow", "led_green",
               "barrier_relay", "intercom_ptt", "ticket_enable"]

def setup():
    GPIO.setmode(GPIO.BCM)
    GPIO.setwarnings(False)

    for pin_name in INPUT_PINS:
        GPIO.setup(PINS[pin_name], GPIO.IN, pull_up_down=GPIO.PUD_DOWN)

    for pin_name in OUTPUT_PINS:
        GPIO.setup(PINS[pin_name], GPIO.OUT)
        GPIO.output(PINS[pin_name], GPIO.LOW)

def test_inputs():
    print("\n═══ INPUT PIN TEST ═══")
    for pin_name in INPUT_PINS:
        pin = PINS[pin_name]
        state = GPIO.input(pin)
        status = "✅ LOW (idle)" if state == GPIO.LOW else "⚠️  HIGH (triggered)"
        print(f"  GPIO {pin:2d} ({pin_name:20s}): {status}")

def test_leds():
    print("\n═══ LED TRAFFIC LIGHT TEST ═══")
    led_sequence = [
        ("led_red",    "RED",    1),
        ("led_yellow", "YELLOW", 1),
        ("led_green",  "GREEN",  1),
    ]
    for pin_name, color, duration in led_sequence:
        pin = PINS[pin_name]
        GPIO.output(pin, GPIO.HIGH)
        print(f"  GPIO {pin:2d} → {color:6s} ON")
        time.sleep(duration)
        GPIO.output(pin, GPIO.LOW)
        print(f"  GPIO {pin:2d} → {color:6s} OFF")

def test_barrier():
    print("\n═══ BARRIER RELAY TEST ═══")
    pin = PINS["barrier_relay"]
    GPIO.output(pin, GPIO.HIGH)
    print(f"  GPIO {pin:2d} → BARRIER OPEN")
    time.sleep(2)
    GPIO.output(pin, GPIO.LOW)
    print(f"  GPIO {pin:2d} → BARRIER CLOSE")

def test_intercom():
    print("\n═══ INTERCOM PTT TEST ═══")
    pin = PINS["intercom_ptt"]
    for i in range(3):
        GPIO.output(pin, GPIO.HIGH)
        time.sleep(0.2)
        GPIO.output(pin, GPIO.LOW)
        time.sleep(0.1)
    print(f"  GPIO {pin:2d} → PTT pulse × 3 (call signal)")

def test_ticket():
    print("\n═══ TICKET DISPENSER TEST ═══")
    pin = PINS["ticket_enable"]
    GPIO.output(pin, GPIO.HIGH)
    print(f"  GPIO {pin:2d} → TICKET ENABLED")
    time.sleep(0.5)
    GPIO.output(pin, GPIO.LOW)
    print(f"  GPIO {pin:2d} → TICKET DISABLED")

def main():
    print("╔══════════════════════════════════════════╗")
    print("║   TollGate GPIO Test Suite v1.0          ║")
    print("╚══════════════════════════════════════════╝")

    setup()
    test_inputs()
    test_leds()
    test_barrier()
    test_intercom()
    test_ticket()

    print("\n═══ ALL TESTS COMPLETE ═══")
    GPIO.cleanup()

if __name__ == "__main__":
    main()
✅ Expected Output: All GPIO pins should report LOW for inputs and toggle correctly for outputs. If any pin reads HIGH when it shouldn't, check wiring and pull-down resistors before proceeding.

Troubleshooting Table

Common issues encountered during lane controller installation and deployment. Most GPIO problems stem from wiring errors or permission issues.

SymptomLikely CauseFix
GPIO permission denied User not in gpio group, or Docker container lacks host GPIO access Run sudo usermod -aG gpio pi, add --device /dev/gpiomem to Docker run
Loop detector always HIGH Missing pull-down resistor, or inductance too high Add 10kΩ pull-down from GPIO to GND, recalibrate detector module
LED lights not responding MOSFET gate not driven, or wrong GPIO numbering (physical vs BCM) Verify using BCM numbering in code, check MOSFET gate resistor (1kΩ)
Ticket dispenser no output Baud rate mismatch, TX/RX swapped, or 12V power missing Set dispenser to 9600 baud, swap TX/RX wires, verify 12V supply with multimeter
Intercom has no audio USB sound card not recognized, PulseAudio not running Check arecord -l and aplay -l, install pulseaudio, restart service
Barrier doesn't open/close Relay coil voltage mismatch, optocoupler blown Verify 24V AC supply, replace PC817 optocoupler, check relay click on GPIO toggle
Docker container crashes on boot systemd service starts before GPIO is ready Add After=systemd-udev-settle.service and RestartSec=15 to service file
RPi overheating / throttling No heatsink, ambient temp too high, continuous CPU load Add FLIRC aluminum case, monitor with vcgencmd measure_temp, add fan if >60°C
Serial garbled output Baud rate mismatch, voltage level incompatible (5V vs 3.3V) Set both ends to 9600 baud, add 3.3V↔5V level shifter if needed
MicroSD card corruption Power loss during write, excessive write cycles from logging Use A2-rated microSD, enable read-only overlay, mount /tmp as tmpfs
