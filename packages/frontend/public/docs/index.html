🔧 Hardware Components

Every device in the toll lane system — click to view installation guide

UHF RFID Reader

ZKTeco UHF300 / Impinj R420

Long-range passive UHF tag reader for vehicle identification. Reads tags at 3–12m distance with >200 reads/second.

TCP/IP 920–925 MHz Port 5000 3–12m range

ANPR Camera

Hikvision DS-2CD7A46G0-IZHS

AI-powered Automatic Number Plate Recognition camera with >99% accuracy. Captures plates in all lighting conditions.

ISAPI 4MP Resolution RTSP :554 PoE

Barrier Gate

FAAC 640 Electromechanical

Boom barrier with auto-reverse safety, battery backup, and serial/TCP control. Opens in 1.5–4 seconds.

RS232/TCP 1.5–4s open 3–8m lane IP55

Lane Controller

Raspberry Pi 4 (4GB)

Edge computing device running Docker containers for local toll processing. Controls all lane peripherals via GPIO.

GPIO 40-pin Gigabit ETH Docker SQLite

LED Traffic Signal

3-Aspect (Red / Yellow / Green)

Overhead traffic signal controlling vehicle flow. 150W LED with 200m+ visibility distance.

GPIO Control 150W LED 200m visibility

Vehicle Loop Detector

Inductive Loop Sensor

Detects vehicle presence via inductive loop embedded in road surface. Triggers toll processing sequence.

GPIO Input 100kHz In-ground

Intercom System

Master-Slave Audio Station

Two-way audio communication between toll booth operator and driver for assistance.

GPIO PTT 2-wire audio Weather-proof

Ticket Dispenser

Serial Thermal Printer

Dispenses paper toll tickets with vehicle class, entry time, and QR code for manual toll collection.

UART Serial Thermal Auto-feed
