Serial Control (RS232)

Primary — Direct UART connection

Direct serial connection from RPi GPIO UART (TX/RX) through MAX232 level shifter to FAAC 640 control board. Lowest latency, highest reliability.

9600 baud 8N1 GPIO 14/15 Recommended

TCP/IP Control

Alternative — Ethernet via WIZnet module

TCP client connection from RPi to barrier gate's integrated WIZnet W5500 Ethernet module. Requires network infrastructure but supports remote control.

Port 5000 TCP Client Static IP Remote

Modbus RTU Control

SCADA integration — RS485 bus

Modbus RTU over RS485 allows SCADA integration and multi-device bus topology. Each barrier assigned a unique slave ID (1–247).

RS485 Slave ID: 1 9600 baud SCADA

Packet Format

┌──────┬──────┬──────┬──────┬──────┐
│ HEAD │ ADDR │ CMD  │ DATA │ CHK  │
│ 0xFF │ 0x01 │ 0xXX │ ...  │ 0xXX │
└──────┴──────┴──────┴──────┴──────┘

HEAD  = Fixed header (0xFF)
ADDR  = Device address (0x01 = primary)
CMD   = Command byte
DATA  = Payload (variable length)
CHK   = XOR checksum of all previous bytes

Checksum Calculation

// XOR checksum example for OPEN command
bytes = [0xFF, 0x01, 0x01, 0x01]
chk = 0xFF ^ 0x01 ^ 0x01 ^ 0x01
    = 0xFF
    = 0x02  // after wrap

// Final packet: FF 01 01 01 02

// Node.js implementation
function calcChecksum(buf) {
  let chk = 0;
  for (const b of buf) chk ^= b;
  return chk & 0xFF;
}

🛡️ Safety Features

Built-in safety mechanisms to prevent vehicle damage and ensure operator safety

Auto-Reverse on Obstruction

Primary collision prevention

If the boom arm contacts an obstruction while closing, the motor current spikes above threshold (3A). The controller immediately reverses direction and opens the boom. Prevents vehicle damage and passenger injury.

Current Spike Detection <50ms Response Auto-Recovery

Safety Photo-Eyes (2×)

Infrared beam obstruction detection

Dual infrared photo-eye sensors at 300mm and 500mm height detect vehicle presence in the boom path. If beam is broken during closing cycle, barrier immediately reverses. Required by international safety standards.

Infrared 940nm 30m Range Fail-safe (NC) IP67

Battery Backup

Emergency operation during power loss

12V 7Ah sealed lead-acid battery provides 50+ open/close cycles during power outage. Automatic switchover in <10ms. Low-voltage cutoff at 10.5V prevents deep discharge damage.

12V 7Ah SLA 50+ Cycles Auto Switchover Float Charge

Motor Overheat Protection

NTC thermistor thermal cutoff

NTC thermistor embedded in motor winding monitors temperature. If motor exceeds 80°C, controller reduces PWM duty cycle. At 100°C, motor is locked out for 60s cooldown. Prevents permanent winding damage.

NTC 10kΩ 80°C Derate 100°C Lockout 60s Cooldown

Manual Release Handle

Mechanical override for emergency

Key-operated manual release handle on the barrier housing disengages the motor brake, allowing manual boom operation. Used during maintenance, power loss (no battery), or emergency evacuation.

Key-lock Brake Release Emergency Only

Limit Switches (2×)

Upper and lower position detection

Spring-actuated microswitches detect fully open and fully closed positions. Prevents motor overrun and mechanical damage. Adjustable actuator arm allows fine-tuning of travel limits.

NC Contacts IP67 Sealed 10M Cycles
