Plaza Server (Raspberry Pi)

Hardware

  • Raspberry Pi 4 (2GB+ RAM)
  • 32GB+ microSD card
  • USB-to-Serial RFID reader
  • Ethernet/WiFi connection
  • UPS battery backup

Software

  • SQLite local database
  • Built-in admin panel (port 4000)
  • RFID reader (Serial/TCP)
  • Sync engine with queue
  • Docker containerized

Offline Operation

1. Vehicle arrives at plaza

2. RFID tag scanned locally

3. Toll calculated from local rates

4. Transaction stored in SQLite

5. Added to sync queue

6. Synced to HQ when online

Sync Protocol

Plaza → HQ

• Toll events (entry/exit)

• Transaction records

• Violation reports

• Device status updates

▼ Every 30 seconds

HQ → Plaza

• Vehicle registrations

• Toll rate updates

• RFID tag blacklists

• Configuration changes

▼ Every 60 seconds

Conflict Resolution

Last-write-wins with exponential backoff retry. Manual force retry available from admin panel.

Plaza Server (Raspberry Pi)

# Deploy Plaza
chmod +x scripts/deploy-plaza.sh
./scripts/deploy-plaza.sh \
  plaza-001 "0 Mile" "0MILE" \
  "http://hq:3000" "token"

Port 4000: Plaza API & Admin Panel
Auto: RFID reader detection
Auto: Sync engine startup
